קיקבוב (KickBob) - PRE ALPHA 0.0.4
=====================================
התוכנה עשה EMUIO הסטרימר בקיק
https://kick.com/emuio

מה זה?
דפדפן קטן לצפייה בסטרימים העבריים של Kick: כרטיסיות, שורת כתובת עם חיפוש בגוגל, חיפוש קליפים,
סימניות, ערוצים מועדפים עם התראות כשהם עולים לשידור, היסטוריית צפייה עם ייצוא, רמות, עיצוב ל-Kick,
תרגום הממשק לעברית, ומסגרת חלון וסמן בסגנון Chrome.

דרישות
- Windows 10 או 11
- Python 3.9 ומעלה מ-https://www.python.org/downloads/  (חשוב: לסמן "Add Python to PATH" בהתקנה)
- חיבור אינטרנט (בהפעלה הראשונה מותקנת החבילה pywebview לבד)

הפעלה מהירה
1. חלץ את כל הקבצים לתיקייה אחת.
2. הרץ את KickBob.bat

בניית קובץ EXE במחשב שלך
1. הרץ את build_exe.bat  (דורש אינטרנט בפעם הראשונה)
2. הקובץ KickBob_PRE_ALPHA_0.0.4.exe ייווצר באותה תיקייה.

EXE מוכן להפצה + עדכון אוטומטי (דרך GitHub, בחינם)
1. צור מאגר חדש ב-GitHub והעלה אליו את כל הקבצים מהתיקייה הזאת, כולל התיקייה הנסתרת .github
2. צור גרסה: Releases ← Draft a new release ← תג חדש, למשל v0.0.4 ← Publish.
   (או: Actions ← Build KickBob EXE ← Run workflow, כדי לבדוק בלי גרסה.)
3. אחרי כמה דקות מופיע ב-Release הקובץ KickBob.exe. זה ה-EXE המוכן: אפשר לשתף את הקישור אליו.
4. בקיקבוב: הגדרות ← עדכונים ← מקור העדכונים: הקלד owner/repo של המאגר שלך.
   מעכשיו, כשתפרסם Release חדש עם תג גבוה יותר, קיקבוב יציע לעדכן (באישור שלך בלבד).
   הערה: הגדר רק מאגר שאתה סומך עליו, כי העדכון מוריד קוד שרץ במחשב שלך.

התראות כשערוץ עולה לשידור
- הוסף ערוצים ב: תפריט K ← ערוצים מועדפים (אפשר גם לייבא את מי שאתה עוקב אחריו, ניסיוני).
- קיקבוב פותח חלון רקע מוסתר שבודק אחת לדקה. צריך להיות מחובר לחשבון Kick לחלק מהבדיקות.
- ההתראה כוללת התראת Windows, צליל והבהוב בשורת המשימות. אפשר לכבות בהגדרות ← התראות שידור.

היסטוריית צפייה
- תפריט K ← היסטוריית צפייה (או Ctrl+H). ייצוא ל-CSV (נפתח באקסל) או ל-JSON נשמר בתיקיית ההורדות.

אם יש בעיה
- KickBob.bat --safe   : הפעלה בלי חוסם פרסומות ובלי סמן מותאם.
- python kickbob.py --framed   : מסגרת חלון רגילה של Windows במקום המסגרת בסגנון Chrome.
- קובץ הלוג נמצא ב: %USERPROFILE%\kickbob.log

קיצורי מקלדת
Ctrl+T כרטיסייה חדשה | Ctrl+W סגירה | Ctrl+Tab מעבר | Ctrl+L שורת כתובת | Ctrl+D סימנייה
Ctrl+H היסטוריה | Ctrl+Shift+O סימניות | Ctrl+Shift+Z כיבוי חירום של עיצוב Kick

זו גרסת PRE ALPHA: יכולים להיות באגים.
